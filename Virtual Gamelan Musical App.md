### 🌟 Key Features
- **Authentic Synthesis**: Custom sound engines for **Saron**, **Demung**, **Slenthem**, **Bonang**, **Gong**, and **Kendhang** using high-fidelity FM and metallic synthesis.
- **Traditional Tunings**: Instant toggle between **Slendro** and **Pelog** scales.

### 🛠️ Technical Stack
- **Framework**: React + Vite
- **Audio Engine**: Tone.js (Synthesis-based for speed and self-containment)
- **Styling**: Vanilla CSS (Custom Design System)

### 🎵 How to Play
1. Click **START AUDIO** on the top panel to initialize the sound engine.
2. **Saron/Slenthem**: Use keys **1, 2, 3, 4, 5, 6, 7, 8**.
3. **Kendhang (Drum)**: Use keys **Q** (Dung) and **W** (Tak).
4. **Gong**: Press the **SPACEBAR**.
5. Switch scales using the **SLENDRO** and **PELOG** buttons.
